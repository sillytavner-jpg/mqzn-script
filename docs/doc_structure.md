# 明月秋青智脑 — 使用说明书 (A4.x / 最新版)

## 一、智脑是什么？
* 智脑是酒馆的 AI 聊天记忆管家，负责记录、分析并将其注入到 AI 上下文中。
* 核心流程：小总结 (每轮) -> 大总结 V2 (分批或定期) -> KG、动态人设、角色记忆、梦呓更新等。

## 二、快速上手
* 如何安装和启用
* 日常使用无感流程（默认全开就是最优配置）

## 三、面板与核心模块介绍
1. **总览** — 仪表盘、手动/重新总结、批量总结(Batch Summary v2)
2. **角色库 & 记忆控制** — 核心记忆（远期语义召回/完整注入）、近期记忆。支持语义召回（BGE-M3）的开启与配置。
3. **动态人设 (Dynamic Profile V2)** — 事实层 + 表现层，防极端化更新角色状态。
4. **梦呓 (Dreamtalk V2)** — 行为翻译手册，带“禁止误读”机制。
5. **关系档案 (Relationship Analysis)** — 可视化角色间关系与亲密度，支持连回世界书匹配，纯手动触发。
6. **知识图谱 (Knowledge Graph)** — 搭车小总结顺带输出节点（地点/物品）增量，构建网状连接，并根据聊天阶段提取和注入。
7. **事实信息强调 (Fact Emphasis)** — 提取事实组装校验表，防止AI时间和空间错乱。
8. **世界推进 (World Progress)** — 后台非正文时间的推演（主时间线推进+角色独立行动生成），默认关闭。
9. **剧情导演 (Plot Director)** — 模式1（剧情大纲讨论）、模式2（大纲引导校验与适时提示）。
10. **世界书蒸馏 (World Book Distill)** — 用于将长文本世界书精简和特征化为可编辑文本，用于知识下沉（手动使用）。

## 四、核心设置与数据流
* 小总结：每轮正文产生后。
* 大总结 V2：白描时间线 -> 角色记忆和 NSFW 独立解析更新。
* 情绪积累：独立更新模块（每N轮触发）。
* 注入机制：记忆（近期无条件注入，远期用语义召回或全量）。
* 自定义 API (兼容 OpenAI 格式 API)。
* 角色设定管理。

* API 或 Token 满处理
